Current research

Genotype–Phenotype Graph Learning Using Random Forests and Stability Selection

2026–present · CNPq undergraduate research scholarship

Supervisor: Prof. Thiago Rodrigo Ramos · UFSCar

Problem

How can we identify stable relationships between genotypic and phenotypic variables when the number of predictors is large? The project investigates statistical dependencies and how to represent them as graphs.

Methodology

Random Forests estimate variable importance. Repeated sampling and stability selection help assess which relationships persist across runs, supporting the construction of graph representations.

Current work

Developing data-processing and analysis workflows in Python, studying variable importance and stability, and building graph representations with NetworkX.

Outputs

The public research repository contains analysis code and documentation. Raw genomic data are not distributed with it.
